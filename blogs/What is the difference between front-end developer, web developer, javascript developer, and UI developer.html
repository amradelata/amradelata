What is the difference between front-end developer, web developer, javascript developer, and UI developer

Date: 23/1/2020

There’s a lot of overlap here. These can very well describe the exact same position. But there are obvious differences in emphasis, and some more subtle differences in connotation. I would expect a “front-end developer” to be someone capable dealing with a web application that is in fact pretty complex and heavy on the front end. And that would be a job description suggesting that there are others dealing with any server-side stuff. I would expect “web developer” to describe a more entry level position for someone with general knowledge of browser scaffolding (HTML + CSS, with some basic JS) but also some knowledge of web servers. It implies a more junior role, but it may also mean “someone who can single-handedly develop, host, and support our intranet website”. A “javascript developer” is obviously someone with a focus on coding JS, usually client-side, and would not be expected to know or do much beyond that. A “UI developer” would be someone with knowledge of all aspects of a normal website, and additionally some experience in (re-)designing user interfaces to be more friendly. Even more so than “front-end”, the job title describes someone who can take ownership of the front end of a fairly complex web application (few webpages out there deserve to be called UI’s).

"Guruganesh Mariyappan"

Web developer I feel is a generalized term for someone who works on websites. Mainly you’d find 3 kinds of ‘web developers’: back end developer, front end and ‘full stack’ Usually the back end guy mainly focuses on the server side while the front end guy does pretty much everything with HTML, CSS and JS. Full stack developer is a term for someone who is working both on the front end and on the back end. So a back end developer is a web developer, but a web developer is not necessarily a back end developer.
